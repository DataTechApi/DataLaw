# DataLaw — Backend

Ingestão e processamento de dados do DataJud (camadas bronze, silver e gold).

## Ambiente

```bash
uv sync
```

```bash
uv run task test       # testes
uv run task lint       # ruff
uv run task typecheck  # mypy
```
